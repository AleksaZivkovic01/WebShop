A full-stack demo web application built with **ASP.NET Core Web API** and **React**.  
The project demonstrates modern web development practices including clean architecture, authentication, and product/order management.


## Tech Stack

### Backend
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- JWT Authentication

### Frontend
- React
- Axios
- React Router
- Context API 

## Features

- User registration and login
- JWT-based authentication
- Product listing and details
- Shopping cart functionality
- Order creation and management
- Admin product management
